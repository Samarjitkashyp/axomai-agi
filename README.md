## 🚀 Getting Started & Installation

### Prerequisites
- **Python:** Version 3.11 or higher
- **Database:** PostgreSQL 14+ with `pgvector` extension (Database name: `axomai_agi`)
- **Operating System:** Windows 10/11, Ubuntu 22.04+, or macOS Sonoma+

### Step-by-Step Setup

```powershell
# 1. Clone the repository
git clone https://github.com/Samarjitkashyp/axomai-agi.git
cd axomai-agi

# 2. Create and activate a Python virtual environment
python -m venv .venv
# On Windows:
.venv\Scripts\Activate.ps1
# On Linux/macOS:
source .venv/bin/activate

# 3. Install required dependencies
pip install -r requirements.txt

# 4. Set the PYTHONPATH environment variable
# On Windows PowerShell:
$env:PYTHONPATH="src"
# On Linux/macOS:
export PYTHONPATH="src"

# 5. Launch the Sovereign War Room Studio
python -m uvicorn axomai.api.app:app --host 127.0.0.1 --port 8080 --reload
```

Open your browser and navigate to:
