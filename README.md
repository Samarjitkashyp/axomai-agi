## 🚀 Getting Started

### Prerequisites
- Python 3.11+
- PostgreSQL 14+ (Local database: `axomai_agi`)

### Installation & Execution
```powershell
# 1. Clone repository
git clone https://github.com/Samarjitkashyp/axomai-agi.git
cd axomai-agi

# 2. Activate virtual environment
.venv\Scripts\Activate.ps1

# 3. Set Python path
$env:PYTHONPATH="src"

# 4. Launch visual web intelligence server
python run_panel.py --port 8080
```
Open **[http://127.0.0.1:8080](http://127.0.0.1:8080)** to access the Sovereign War Room.

### Run End-to-End Verification Suite
```powershell
$env:PYTHONPATH="src"
python scratch/test_all_syndicates.py
python scratch/test_y_series_agents.py
python scratch/test_advanced_global_agents.py
```
